# Unlisted Explorer

A Geometry Dash Geode mod project by Clyde.

## Current status — v0.1.0

This is the initial project setup. It adds an **Unlisted Explorer** button to the Geometry Dash main menu and opens an information popup.

The following features are **not implemented yet**:
- Searching for creators or players
- Discovering unlisted levels
- Showing profile comments when the server makes them available

The mod cannot bypass server-side privacy or retrieve data that Geometry Dash does not return.

## Build

This project uses the Geode SDK and the official Geode build workflow. Open the repository's **Actions** tab and run **Build Geode Mod**, or push a commit to trigger a build.

See the [Geode getting started guide](https://docs.geode-sdk.org/getting-started/) for SDK setup and build requirements.
